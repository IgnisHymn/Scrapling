# 计划：自动化日期选择功能

## 目标
在 `main.py` 中实现全自动日期选择，每次运行时自动选择前天的日期。

## 逻辑说明
- 今天是 2026-07-17
- 目标日期：2026-07-15（前天）
- 起始日期 = 结束日期 = 15号

## 实现方案

### 1. 修改 `page_parser.py`

添加新方法 `select_date_range()`：
- 找到日期范围下拉菜单
- 选择 "Custom" 选项
- 点击日期按钮打开日历
- 计算前天的日期
- 在日历中找到对应日期并点击
- 点击 Confirm

### 2. 修改 `main.py`

在访问变现页面和仪表板页面后，调用日期选择方法。

## 关键代码

```python
from datetime import datetime, timedelta

# 计算前天日期
today = datetime.now()
target_date = today - timedelta(days=2)
target_day = target_date.day  # 15

# 在日历中找到对应日期
available_dates = await page.locator('.TUXCalendar-dateButton:not([disabled])').all()
for date_btn in available_dates:
    date_text = await date_btn.locator('.TUXCalendar-dateCircle').inner_text()
    if date_text == str(target_day):
        await date_btn.click()
        break
```

## 月份切换逻辑

如果目标日期是上个月：
1. 获取当前日历显示的月份
2. 点击左箭头切换到上个月
3. 找到目标日期并点击

## 关键选择器

```python
# 日期范围下拉菜单
'[role="combobox"]'

# Custom 选项
'[role="option"]:has-text("Custom")'

# 日期按钮（打开日历）
'.TUXDatePicker-button'

# 可选日期按钮
'.TUXCalendar-dateButton:not([disabled])'

# 日期数字
'.TUXCalendar-dateCircle'

# 上个月按钮
'.TUXCalendar-prev-month button, button:has(svg path[d*="19.26 24"])'

# Confirm 按钮
'.TUXCalendar-confirm-button'
```
